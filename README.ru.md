# Aftof

[English](README.md) · **Русский**

Приложение для Windows и macOS, которое собирает файлы из множества папок в одну выбранную
копированием или перемещением.

<img width="1170" height="771" alt="aftof_screen" src="https://github.com/user-attachments/assets/a88580e3-5d12-4db7-8e1e-30538ff876d8" />

## Зачем я его написал

После каждой поездки у меня остаётся десяток папок: выгрузки с телефона, папки по датам с камеры,
что-то присланное в мессенджерах и скачанное из облака. Чтобы разобрать всё это, я каждый раз открывал
папки по очереди, выделял файлы, перетаскивал в общую папку, потом разбирался с одинаковыми именами
вроде `IMG_0001.jpg`, которые есть сразу в трёх местах. На десяти папках это превращается в полчаса
монотонной работы, и я обычно где-нибудь ошибался: то файл терялся, то перезаписывался.

Aftof делает это за один проход: указываешь папки, видишь все файлы одним списком, снимаешь галочки
с ненужных и нажимаешь одну кнопку.

Ещё я часто работаю с проектами в игровых движках — там в ассетах тоже копятся неразобранные файлы,
и Aftof помогает быстро разложить их по местам.

## Что умеет

- Добавить сразу несколько папок через диалог выбора или перетаскиванием в окно.
- Показать файлы из всех папок одним списком: имя, папка-источник, размер, дата, миниатюра для фото.
- Отобрать нужное: поиск по имени, фильтры по типу (фото, видео, аудио, документы, архивы),
  выделение диапазона кликом с Shift.
- Скопировать или переместить выбранное в одну папку, режим переключается перед запуском.
- Показать прогресс с возможностью остановиться и отчёт в конце: сколько перенесено, пропущено,
  сколько не получилось и почему.

Настройки, выбранная папка назначения, тема и язык запоминаются между запусками.

## Что происходит с файлами

Несколько вещей, которые я специально доводил до предсказуемого поведения:

- **Одинаковые имена.** Если файл с таким именем уже есть в папке назначения, можно переименовать
  новый (`фото (2).jpg`), пропустить его или заменить существующий. Выбор сохраняется.
- **Подпапки.** Поиск во вложенных папках включён по умолчанию. При переносе структуру можно
  сохранить или сложить всё плоским списком в одну папку.
- **Перенос между дисками.** На другой том файл нельзя просто переименовать, поэтому он копируется,
  и только после успешной записи удаляется оригинал.
- **Даты.** Дата изменения файла сохраняется, чтобы не сбилась сортировка в галерее.
- **Скрытые и системные файлы** (`.DS_Store`, `Thumbs.db` и прочее) по умолчанию не попадают в список.

## Установка

Готовые сборки лежат в [Releases](https://github.com/vladane/aftof/releases):

- macOS — `.dmg` (отдельно для Apple Silicon и Intel);
- Windows — `.exe` (обычный установщик, можно выбрать папку).

Приложение не подписано сертификатом разработчика, поэтому при первом запуске система осторожничает.
На macOS нужно открыть «Системные настройки → Конфиденциальность и безопасность» и разрешить запуск,
на Windows — нажать «Подробнее → Всё равно запустить» в окне SmartScreen. Внутри нет ни аналитики, ни
сети: приложение работает только с файлами, которые вы сами выбрали.

## Языки

Интерфейс переведён на русский, английский, немецкий, испанский, французский, португальский,
китайский и японский. При первом запуске подхватывается язык системы, дальше язык переключается
кнопкой с глобусом в правом верхнем углу — сразу, без перезапуска. Вместе с подписями меняются
системные диалоги выбора папок и формат дат, чисел и размеров.

Если хочется добавить свой язык: скопируйте `src/shared/i18n/locales/en.ts`, переведите строки и
допишите код языка в `LOCALES` и `LOCALE_NAMES` в `src/shared/i18n/types.ts`. TypeScript сам покажет,
если какая-то строка забыта.

## Сборка из исходников

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev        # запуск с горячей перезагрузкой
npm run typecheck  # проверка типов
npm run dist:mac   # .dmg в release/
npm run dist:win   # .exe в release/
```

Установщик для Windows собирается на Windows: с macOS для этого нужен wine, и результат непредсказуем.
Иконка генерируется скриптом `node build/make-icon.mjs`, дальше electron-builder сам делает из PNG
`.icns` и `.ico`.

Стек простой: Electron, React, TypeScript, electron-vite. Вся работа с файлами — в главном процессе
(`src/main`), интерфейс — в `src/renderer`, переводы и общие типы — в `src/shared`.
